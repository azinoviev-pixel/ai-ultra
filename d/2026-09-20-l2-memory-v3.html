Что в файл, что не в чат

О чём. Правило на завтра нельзя оставлять только в вчерашнем чате.

Куда. В работу с моделью: тон, запреты, формат сдачи, что нельзя трогать.

Зачем. Новый чат не продолжает вчерашний контекст. Без файла или явной памяти продукта правило пропадает.

1. Крюк

Ты в длинном чате сказал: «сдачу пиши одним абзацем». Завтра новый чат. Снова простыня. Правило умерло вместе с сессией. Знал только вчерашний контекст.

2. Цель

После урока ты сможешь: взять одно рабочее правило, положить его в свой файл или в явную память продукта, открыть новый чат и за короткое время проверить — правило сработало только с этой опорой.

Артефакт проверки: файл или строка в списке памяти + одна строка результата.

3. Механизм: три разных слоя

Слой A — session / context

Context window — максимум токенов на один запрос (вход, выход, reasoning). Что не влезло, может обрезаться.

Источник: Conversation state — OpenAI (чтение 20.09.2026).

Продукт может сжимать историю (compaction): несёт «key prior state» меньшим числом токенов, результат «opaque and not intended to be human-interpretable». Это не твой читаемый файл с правилом.

Источник: Compaction — OpenAI (чтение 20.09.2026).

Anthropic context editing чистит stale tool results внутри окна (clear_tool_uses_20250919). На их internal agentic search eval (блог 29 сентября 2025): memory tool + context editing — +39% к baseline; только context editing — +29%; в 100-turn web search — −84% token consumption и завершение того, что иначе падает от exhaustion. Это метрики Anthropic на их стенде, не закон твоей заметки. Смысл для урока: даже «умный» агент без внешнего store упирается в окно.

Источник: Context management — Anthropic · Context editing docs (чтение 20.09.2026).

Чья метрика: Anthropic, internal evaluation (agentic search / token consumption). Не наш замер. URL: https://claude.com/blog/context-management (29 сентября 2025; чтение 20.09.2026).

Слой B — saved memory продукта

OpenAI (апр. 2025): два способа — «saved memories» you’ve asked it to remember и «chat history» insights. Temporary chat — без memory.

Источник: Memory and new controls for ChatGPT (чтение 20.09.2026).

Help OpenAI: saved memories хранятся отдельно от chat history; удаление исходного чата само не удаляет saved memory; history-derived может меняться; «does not retain every detail»; temporary «do not create or update memories».

Источник: Memory in ChatGPT · Temporary Chat (чтение 20.09.2026).

Dreaming (пост 4 июня 2026): April 2024 — saved memories; April 2025 — first dreaming; June 4, 2026 — текущий пост. Продукт сам синтезирует freshness. Это не твой md.

Источник: Dreaming (чтение 20.09.2026).

Claude: generate memory из чатов; отдельные project memory spaces; pause — не использует и не пишет новую. Topics в настройках — список файлов, которые можно читать, править, удалять (блог 25 авг. 2026).

Источник: Chat search and memory · Claude's memory works everywhere (чтение 20.09.2026).

Слой C — file store

Anthropic Memory tool: directory of memory files; persist between sessions; without keeping everything in the context window; пишет под /memories; storage у тебя / у приложения.

Источник: Memory tool (чтение 20.09.2026).

Тот же блог 29.09.2025: file-based system вне context window, persist across conversations. Вместе с числами выше: вынос знаний из окна + чистка окна у Anthropic измеримо лучше, чем надежда «чат сам помнит».

Вывод: чат = сессия · продукт = чужая сводка · файл = твоя опора.

4. Три worked examples

Тон

Неправильно. В чате: «пиши коротко, без канцелярии». Новый чат без строки — снова канцелярия.

Правильно. Файл: Тон: коротко, без канцелярии. Новый чат + файл (или строка видна в списке памяти продукта).

Запрет

Неправильно. В чате: «клиенту не обещай сроки без моего да». Новый чат — модель ставит срок.

Правильно. Файл: Клиенту не обещать сроки без моего «да». Новый чат с опорой.

Формат сдачи

Неправильно. В чате: «сдачу одним абзацем». Завтра снова простыня.

Правильно. Файл: Сдача: один абзац. Файл во вложении, не путь. Новый чат с опорой.

Temporary chat для правила на завтра не подходит: memories не создаёт и не обновляет (Temporary Chat).

6. Умение

Записать одно рабочее правило в файл (или в явную память продукта), открыть новый чат и за короткое время проверить: правило сработало только с этой опорой.

7. Практика · 15 минут

  1. Возьми одно правило из своей работы (тон, запрет или формат). Одна-две строки.
  2. Запиши в файл — или явно «запомни …» и открой список памяти продукта (строка там есть).
  3. Открой новый чат: не продолжение вчерашнего; не temporary, если проверяешь память продукта.
  4. Дай задачу, где правило должно сработать. Файл подложи или положись на память продукта.
  5. Заполни блок. Стоп.

Артефакт:

правило: …
опора: файл | память продукта (строка в списке: да)
новый чат (не temporary, если память продукта): да
задача: …
результат: сработало с файлом | сработало с памятью продукта | без опоры правило умерло
нельзя: правило только в старом чате; простыня вместо одного правила; сравнение пяти продуктов

Сдал

  • Есть одно короткое правило.
  • Есть артефакт опоры: файл или строка из списка памяти.
  • Есть одна строка результата ровно в формулировке Sensei.
  • Строка «нельзя» на месте.

Не сдал

  • Правило только в старом чате.
  • Простыня вместо одного правила.
  • Сравнение пяти продуктов.
  • База на тысячу документов.
  • Temporary-чат при проверке памяти продукта.
  • История / «почувствовал» без артефакта и строки результата.
  • Чужой eval вместо своей проверки.

Три вопроса

  1. Правило сказал только вчерашнему чату, сегодня новый чат без файла. Какой результат по Sensei?
  2. После «запомни» не открыл список памяти. Сдал?
  3. Хочется сравнить пять продуктов «кто помнит лучше». Можно?
Ответы
  1. Без опоры правило умерло.
  2. Нет. Нужна видимая строка в списке памяти или файл.
  3. Нет. Сравнение пяти продуктов — провал.

8. Граница

Сегодня не сравнивать «кто помнит лучше» и не строить базу на тысячу документов. Одно правило. Одна опора. Одна проверка.

Числа +39% / +29% / −84% — только internal eval Anthropic на https://claude.com/blog/context-management. Не переносить на свою заметку как закон.
