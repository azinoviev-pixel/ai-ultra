Что в файл, что не в чат

О чём. Правило, которое нужно завтра, пишешь в файл (или в явную память продукта). Разовое оставляешь в чате.

Куда. В работу с моделью: тон, запреты, формат сдачи, что нельзя трогать.

Зачем. Новый чат вчерашние указания сам не тащит. Без файла ты каждый раз объясняешь заново.

Правило

Нужно завтра или через неделю Куда
Тон, формат сдачи, запрет, «этого не трогать» Файл у тебя или явная память продукта (список в настройках)
Черновик на один раз, мозговой штурм, цифры «только сегодня» Только этот чат
Секрет, который нельзя светить снова Не в чат и не в память продукта

Тест на одно предложение: «Это понадобится в новом чате завтра?» Да → файл или явная память. Нет → чат.

Факты продукта (не вместо файла)

OpenAI разделяет два рычага: Reference saved memories и Reference chat history. Saved — то, что явно держат. History — куски прошлых чатов; они могут меняться. ChatGPT «does not retain every detail» из истории. Temporary chat не пишет memories.

Источник: Memory in ChatGPT (чтение 20.09.2026).

Пост OpenAI от 4 июня 2026: dreaming собирает память продукта из многих чатов в фоне. Первый шаг reference вне списка saved — апрель 2025. Это не твой файл на диске. Это сводка продукта.

Источник: Dreaming (чтение 20.09.2026).

Claude: chat search + Generate memory (topics); можно править и ставить на паузу. У проектов — отдельная память. Incognito в memory не идёт.

Источник: Claude chat search and memory (чтение 20.09.2026).

Anthropic Memory tool для API: знания в файлах /memories у клиента между сессиями. Принцип тот же: долгое — файл, не окно чата.

Источник: Memory tool (чтение 20.09.2026).

Что писать в файл

Одна-две строки. Примеры:

  • Клиенту не обещать сроки без моего «да».
  • Сдача — файл во вложении, не путь.
  • Тон: коротко, без канцелярии.
  • Не трогать: логины, карты, чужие секреты.

Не писать: простыню вчерашнего чата; «подумай сам»; секрет, который нельзя отправлять модели снова.

Что делать в новом чате

  1. Открой новый чат (не продолжение вчерашнего).
  2. Подложи файл или проверь, что правило видно в списке памяти продукта.
  3. Дай задачу, где правило должно сработать.
  4. Нет правила в опоре — модель ему не обязана следовать.

Умение

Записать одно рабочее правило в файл (или в явную память продукта), открыть новый чат и проверить за короткое время: правило сработало только с этой опорой.

Граница. Сегодня не сравнивать «кто помнит лучше» и не строить базу на тысячу документов. Одно правило. Одна опора. Одна проверка.

Факт Probe

Два замера с одной страницы Anthropic (Managing context on the Claude Developer Platform; September 29, 2025; чтение 20.09.2026). Их внутренний eval agentic search и токены агента — не «насколько лучше правило в md у тебя».

context editing alone: +29%[1]

100-turn web search: −84% токенов[1]

Правило держит файл или store, не окно чата после конца сессии. Чужие +39% / +29% / −84% — не закон твоей полки md.

Практика · пятнадцать минут

Одно правило из своей реальной работы: тон, запрет или формат сдачи. Одна короткая фраза. Не простыня.

Два хода подряд. Одно и то же правило. Одна и та же короткая задача для модели.

Ход А — оставить в чате

В любом текущем чате скажи правило модели один раз. Потом открой новый чат без этого правила в файле и без явной памяти продукта. Ту же задачу дай без файла и без «запомни». Запиши, что вышло: правило сработало или умерло.

Ход Б — в файл (или явную память)

То же правило коротко запиши в свой файл — или явно «запомни …» и открой список памяти, убедись, что строка там. Новый чат. Ту же задачу. Файл подложи или положись на память продукта. Запиши, что вышло.

Стоп. Не третий продукт. Не база на тысячу документов.

Напиши пять строк.

правило (одно, из своей работы): …
ход А (новый чат без файла и без памяти): …
ход Б (куда положил + новый чат с опорой): …
сдача: без опоры — …; с файлом/памятью — …
нельзя: оставлять правило только в чате и надеяться; писать простыню; сравнивать пять продуктов; строить базу на тысячу документов

Сверка · файл

правило: сдача — один абзац, без пути на диске
ход А (новый чат без файла и без памяти): снова простыня, путь мелькнул
ход Б (файл с одним правилом + новый чат, файл подложил): один абзац, пути нет
сдача: без опоры — умерло; с файлом — сработало
нельзя: оставлять правило только в чате и надеяться; писать простыню; сравнивать пять продуктов; строить базу на тысячу документов

Сверка · память продукта

правило: не предлагай сравнивать пять инструментов
ход А (новый чат без файла и без памяти): предложила сравнить три инструмента
ход Б (явная память, строка в списке есть + новый чат): сравнения нет
сдача: без опоры — умерло; с памятью продукта — сработало
нельзя: оставлять правило только в чате и надеяться; писать простыню; сравнивать пять продуктов; строить базу на тысячу документов

Сдал, если на своём правиле есть оба хода и в сдаче видно различие: без опоры vs с файлом или памятью. Нет двух результатов рядом — не сдал.

Три вопроса

1. Сказал правило в длинном чате, новый чат без файла — снова мимо. Что это доказывает за пятнадцать минут?
Правило в чате само между чатами не держится. Нужна опора снаружи: файл или явная память.
2. После хода А правило умерло, после хода Б с файлом сработало. Что пишешь в сдаче?
Без опоры — умерло; с файлом — сработало.
3. Хочется сравнить пять продуктов «кто помнит лучше» вместо двух ходов. Можно?
Нет. Сравнение продуктов — провал. Два хода на одном правиле.

Провал. Сделал только один ход. Оставил правило только в старом чате и надеялся. Написал простыню вместо одного правила. Сравнивал пять продуктов. Строил базу на тысячу документов. Рассказал историю без двух проверяемых ответов модели.
