Правило в файл. Чат сам между днями не держит

О чём. Чат помнит только пока живёт окно разговора. Между днями надёжная память — это твой файл (или явная память продукта), а не «мы же вчера говорили».

Куда. В любую работу с моделью и агентами, где завтра понадобится то же правило: тон, запреты, формат сдачи, имя клиента, что нельзя трогать.

Зачем. Иначе каждое утро ты заново объясняешь одно и то же. Или надеешься на автоматическую память продукта и не проверяешь, что она реально сохранила.

Три полки, не одна

Чат. Контекст текущего разговора. Закрыл окно, начал новый чат, упёрся в лимит — куски выпадают. Для разового черновика нормально. Для правила «навсегда» — слабо.

Память продукта. То, что ChatGPT или Claude сами тащат между чатами: saved memories, сводка истории, memory в настройках. Удобно для предпочтений. Не замена твоему файлу: ты не контролируешь каждое слово так же жёстко, и удаление чата не всегда стирает память.

У OpenAI сейчас два рычага: Reference saved memories (то, что явно попросили помнить) и Reference chat history (куски из прошлых чатов, которые могут меняться). Для того, что должно держаться всегда, Help Center советует именно saved memories — история чатов «не помнит каждую деталь».[1]

Источник: Memory FAQ — OpenAI Help Center · How does “Reference saved memories” work? (чтение 20.09.2026; второй URL сливается в первый).

4 июня 2026 OpenAI описали dreaming: фоновая сборка памяти из многих чатов, сводка обновляется. Это сильнее старых «запомни, что я сказал», но всё равно продукт решает, что вынести наверх.[3]

Источник: Dreaming: Better memory for a more helpful ChatGPT (4 Jun 2026, чтение 20.09.2026).

У Claude память между чатами тоже есть: можно смотреть, править, ставить на паузу; у проектов — отдельное пространство памяти. Help Center отдельно описывает chat search + memory.[4][5]

Источник: Claude chat search and memory · Claude's memory works everywhere (чтение 20.09.2026).

Твой файл. Короткая заметка у тебя: правило, запрет, формат. Завтра открываешь новый чат и кладёшь файл или вставляешь кусок. Это ты контролируешь. Это и есть «что в файл».

Для разработчиков Anthropic отдельно даёт Memory tool: знания живут в файлах под /memories, а не только в окне контекста.[6]

Источник: Memory tool — Claude API (чтение 20.09.2026).

Тебе как сильному пользователю важна не API-схема, а принцип: долгое — в файл (или в явную память, которую ты видишь и правишь). Разовое — в чат.

Что класть в файл

Коротко. Одно правило — одна-две строки.

Примеры, которые завтра пригодятся:

  • «Клиенту не обещать сроки без моего „да“».
  • «В сдаче — файл во вложении, не путь на диске».
  • «Тон: коротко, без канцелярии».
  • «Этого не трогать: логины, карты, чужие секреты».

Не клади в файл простыню вчерашнего чата. Не клади «подумай сам». Не клади секрет, который нельзя светить модели снова.

Что оставить только в чате

Черновик на один раз. Мозговой штурм. Временные цифры «на сегодня». Спор, который завтра уже не нужен.

Если через день правило всё ещё нужно — оно уже не «только в чат». Вынеси.

Живой ход

Вчера в длинном чате ты сказал модели: «всегда пиши сдачу одним абзацем и без пути на диске». Сегодня новый чат. Модель снова льёт простыню. Ты злишься «она же знала». Нет: знал вчерашний чат. Сильный ход: одно правило в свой файл, завтра в новом чате — «работай по этому правилу» + файл или вставка. Или явная команда памяти продукта + проверка в настройках, что оно там есть.

Умение

За пятнадцать минут выписать одно рабочее правило в свой файл (или в явную память продукта, которую видно в настройках), открыть новый чат без вчерашней переписки и проверить: модель следует правилу только когда ты его подложил или когда память продукта его реально показывает.

Граница. Сегодня не строй «умную базу знаний на тысячу документов» и не сравнивай, чей продукт помнит лучше. Одно правило. Один файл или одна явная память. Одна проверка в новом чате.

Правило держит файл или память продукта, не само окно чата между днями. Чужие «30 дней» и «примерно 5×» не закон твоей полки.

На живых страницах Radar нет замера задачи с пятью полями. Есть описание слоёв памяти, сроки удержания логов, дата поста и чужой compute — не стенд урока. Практику на замер не строить.

Практика · пятнадцать минут

Возьми одно правило из своей реальной работы: тон, запрет или формат сдачи. Одно, не простыня.

Запиши его коротко в свой файл — или явно попроси продукт «запомни …» и открой список памяти, убедись, что строка там.

Открой новый чат. Не продолжение вчерашнего.

Дай задачу, где это правило должно сработать. Файл подложи или положись на память продукта — как решил.

За короткое время реши: правило сработало? Напиши себе одну строку результата.

Напиши четыре строки.

правило (одно, коротко): …
куда положил: свой файл / явная память продукта (строка в списке есть)
новый чат + задача: …
сдача: сработало с файлом / сработало с памятью продукта / не сработало — в чате без опоры умерло
нельзя: оставлять правило только в старом чате; писать простыню вместо одного правила; сравнивать пять продуктов

Если сработало с файлом

правило: сдача — один абзац, без пути на диске
куда положил: свой файл с одним правилом
новый чат + задача: напиши сдачу по короткой задаче; файл с правилом подложил
сдача: сработало с файлом — ответ одним абзацем, пути нет
нельзя: оставлять правило только в старом чате; писать простыню вместо одного правила; сравнивать пять продуктов

Если сработало с памятью продукта

правило: не предлагай сравнивать пять инструментов
куда положил: явная память продукта; строка в списке настроек есть
новый чат + задача: попроси помощь по формату ответа без файла
сдача: сработало с памятью продукта — сравнение пяти инструментов не предложила
нельзя: оставлять правило только в старом чате; писать простыню вместо одного правила; сравнивать пять продуктов

Если не сработало

правило: всегда пиши сдачу одним абзацем
куда положил: только вчерашний чат, в файл и память не клал
новый чат + задача: напиши сдачу
сдача: не сработало — в чате без опоры правило умерло; простыня снова
нельзя: оставлять правило только в старом чате; писать простыню вместо одного правила; сравнивать пять продуктов

Сдал, если есть одно короткое правило, видно куда положил (файл или строка из списка памяти), новый чат с задачей и одна строка результата проверки.

Три вопроса

1. Вчера в длинном чате сказал «всегда пиши сдачу одним абзацем». Сегодня новый чат — снова простыня. Что сломалось и что делаешь за пятнадцать минут?
Правило жило только в старом чате. Записываешь одно правило в файл или явную память, открываешь новый чат, проверяешь с опорой.
2. Записал одно правило в файл, открыл новый чат, подложил файл, правило сработало. Что пишешь в сдаче?
Сработало с файлом.
3. Хочется сравнить пять продуктов «кто помнит лучше» или набросать базу на тысячу документов. Можно?
Нет. Сравнение продуктов и база на тысячу документов — провал. Одно правило, одна проверка.

Провал. Оставил правило только в старом чате и надеялся. Написал простыню вместо одного правила. Сравнивал пять продуктов вместо одной проверки. Ушёл строить базу на тысячу документов.
